# Controls:
Presets: `GoogleDrive:\My Drive\Hardwares e Softwares\Gaming Configs\DCS\` 

**Joystick "Axis Tune":**

- Pitch = dead `1` / Curv `5`
- Roll = dead `1` / Curv `5`
- Rudder = dead `1` / Curv `5`
- Throttle = dead `0` / Curv `5`

- **Engine & Fuel:**
    - ATA (more/less) = <span style="color: white; background-color: green; padding:0 5px;">Throttle</span>
    - Throttle to Start (unlock it) =<span style="color: white; background-color: green; padding:0 5px;"> RAlt + Home</span>
    - Throttle to End (lock it) = <span style="color: white; background-color: green; padding:0 5px;">RAlt + End</span>
    - Radiators control Open/Close = <span style="color: white; background-color: green; padding:0 5px;">RAlt+Seta-cima</span> / <span style="color: white; background-color: green; padding:0 5px;">RAlt+Seta-baixo</span>;
    - MW 50 Boost fluid = <span style="color: white; background-color: green; padding:0 5px;">Off=J</span> / <span style="color: white; background-color: green; padding:0 5px;">On=K</span>
        - Release MW50/Fuel (Jettison) = not available
    - MW B4 = not working yet;
    - Release External Fuel tank (Jettison Fuselage stores) = <span style="color: white; background-color: green; padding:0 5px;">NumLock</span>
    - Radiator Flaps Open/Close = <span style="color: white; background-color: green; padding:0 5px;">RAlt+Seta-cima</span> / <span style="color: white; background-color: green; padding:0 5px;">RAlt+Seta-baixo</span>
- **Navigation:**
    - Stabilizer Trim On/Off = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + JOY_BTN_POV1_D (baixo)</span>
        - Trim Elevator D =<span style="color: white; background-color: green; padding:0 5px;"> JOY_BTN_POV1_U (cima)</span>
        - Trim Elevator U = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN_POV1_D</span>
        - Trim Aileron L = not available
        - Trim Aileron R = not available
        - Trim Rudder L = not available
        - Trim Rudder R = not available
    - Gear Up/Down (Undercarriage) = <span style="color: white; background-color: green; padding:0 5px;">G</span>
    - Gear Emergency release = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + G</span>
    - Flaps Up = <span style="color: white; background-color: green; padding:0 5px;">Seta-cima</span>
    - Flaps TakeOff = <span style="color: white; background-color: green; padding:0 5px;">Seta-baixo</span>
    - Flaps Landing = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + Seta-baixo</span>
    - Tail wheel lock/unlock = <span style="color: white; background-color: green; padding:0 5px;">Pôr o manche todo pra trás, centralizado.</span>
    - Wheel Brake Left = <span style="color: white; background-color: green; padding:0 5px;">Seta-Esquerda</span>
    - Wheel Brake Right = <span style="color: white; background-color: green; padding:0 5px;">Seta-Direita</span>
- **Collimator:**
    - EZ42 Gunsight Brightness
        - Increase =<span style="color: white; background-color: green; padding:0 5px;"> RCtrl + JOY_BTN_POV1_D</span>
        - Decrease = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + JOY_BTN_POV1_U</span>
    - EZ42 Gunsight Night Lens Filter On/Off = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + JOY_BTN_POV1_L (esq)</span>
    - EZ42 Gunsight Target Distance:
        - Increase =<span style="color: white; background-color: green; padding:0 5px;"> LCtrl+JOY_BTN_POV1_R</span>
        - Decrease = <span style="color: white; background-color: green; padding:0 5px;">LCtrl+JOY_BTN_POV1_L</span>
    - EZ42 Gunsight Target Wingspan:
        - Increase = <span style="color: white; background-color: green; padding:0 5px;">LWin+JOY_BTN_POV1_R</span>
        - Decrease = <span style="color: white; background-color: green; padding:0 5px;">LWin+JOY_BTN_POV1_L</span>
- **Machineguns & Cannons:**
    - Master Arm On/Off =<span style="color: white; background-color: green; padding:0 5px;"> LCtrl+JOY_BTN1 (Trigger)</span>
        - Fire Nose MGs = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN1</span>
        - Fire MGs with Wing Cowl Cannons =<span style="color: white; background-color: green; padding:0 5px;"> JOY_BTN2</span>
- **Bombs:**
    - Activate bombs (Bomb fusing selector) = <span style="color: orange;">manually</span>;
        - Weapon release = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN3 (bt superior esq)</span>

        - Instrument lights brightness = <span style="color: orange;">manually</span>;
    - Navigation lights On/Off = <span style="color: white; background-color: green; padding:0 5px;">RShift+Insert</span> / <span style="color: white; background-color: green; padding:0 5px;">RCtrl+Insert</span>
- **Miscellaneous:**

        - Open = <span style="color: white; background-color: green; padding:0 5px;">E</span>
        - Close = <span style="color: white; background-color: green; padding:0 5px;">LShift + E</span>
        - Bailout = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + E</span>
