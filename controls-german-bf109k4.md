Axis Tune:
- Pitch = dead 1 / Curv 5
- Roll = dead 1 / Curv 5
- Rudder = dead 1 / Curv 5
- Throttle = dead 0 / Curv 5

- **Engine & Fuel:**
    - ATA (more/less) = Throttle
    - MW 50 Boost fluid = Off=J / On=K
    - Release External Fuel tank (Jettison Fuselage stores) = NumLock
    - Release MW50/Fuel (Jettison) = RShift + NumLock
- **Navigation:**
    - CB Stabilizer Trim:
        - Trim Stabilizer Down = JOY_BTN_POV1_U (cima)
        - Trim Stabilizer Up = JOY_BTN_POV1_D
    - Gear Up/Down = G
    - Gear Emergency release = ==LCtrl + G==
    - Flaps Up = Seta-cima
    - Flaps Down= Seta-baixo
    - Tail wheel lock/unlock = Numpad ,
    - Wheel Brake Left = Seta-Esquerda
    - Wheel Brake Right = Seta-Direita
- **Colimador:**
    - Gun Sight Brightness Decrease = RCtrl + JOY_BTN_POV1_D
    - Gun Sight Brightness Increase = RCtrl + JOY_BTN_POV1_U
    - Gun Sight Smoked Screen On/Off = RCtrl + JOY_BTN_POV1_L (esquerda)
- **Machineguns & Cannons:**
    - Safe Mode On/Off = LCtr + JOY_BTN1
        - Fire MGs = Trigger (JOY_BTN1)
        - Fire Cannon = JOY_BTN2 (bt inferior central)
- **Bombs:**
    - Drop bombs = JOY_BTN3 (bt superior esq)
- **Rockets:**

        - Rocket Emergency Release = ==RCtrl + NumLock==

    - Navigation lights On/Off = Insert
