# Controls:
Presets: `GoogleDrive:\My Drive\Hardwares e Softwares\Gaming Configs\DCS\` 

- **Joystick "Axis Tune":**
	- Pitch = dead `1` / Curv `5`
	- Roll = dead `1` / Curv `5`
	- Rudder = dead `1` / Curv `5`
	- Throttle = dead `0` / Curv `5`

- **Engine & Fuel:**
    - ATA (more/less) = <span style="color: white; background-color: green; padding:0 5px;">Throttle</span>
    - Throttle to Start (unlock it) = <span style="color: white; background-color: green; padding:0 5px;">LWin + Home</span>
    - Throttle to End (lock it) = <span style="color: white; background-color: green; padding:0 5px;">LWin + End</span>
    - Radiators control (Open/Auf - Closed/Zu) = <span style="color: orange;">manually</span>
    - Release External Fuel tank (Jettison Fuselage stores) = <span style="color: white; background-color: green; padding:0 5px;">NumLock</span>
    - Release MW50/Fuel (Jettison) = not available
- **Navigation:**
    - Stabilizer Trim On/Off = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + JOY_BTN_POV1_D (baixo)</span>
        - Trim Elevator D = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN_POV1_U (cima)</span>
        - Trim Elevator U = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN_POV1_D</span>
        - Trim Aileron L = not available
        - Trim Aileron R = not available
        - Trim Rudder L = not available
        - Trim Rudder R = not available
    - Gear Up/Down (Undercarriage) = <span style="color: white; background-color: green; padding:0 5px;">G</span>
    - Gear Emergency release = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + G</span>
    - Flaps Up = <span style="color: white; background-color: green; padding:0 5px;">Seta-cima</span>
    - Flaps Takeoff = <span style="color: white; background-color: green; padding:0 5px;">Seta-baixo</span>
    - Flaps Landing = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + Seta-baixo</span>
    - Tail wheel lock/unlock = <span style="color: white; background-color: green; padding:0 5px;">Pull the Stick fully back</span>
    - Wheel Brake Left = <span style="color: white; background-color: green; padding:0 5px;">Seta-Esquerda</span>
    - Wheel Brake Right = <span style="color: white; background-color: green; padding:0 5px;">Seta-Direita</span>
- **Collimator:**
    - Gun Sight Brightness Decrease = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + JOY_BTN_POV1_D</span>
    - Gun Sight Brightness Increase = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + JOY_BTN_POV1_U</span>
    - Gun Sight Smoked Screen On/Off = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + JOY_BTN_POV1_L (esq)</span>
- **Machineguns & Cannons:**
    - Safe Mode On/Off = <span style="color: white; background-color: green; padding:0 5px;">LCtr + JOY_BTN1</span>
        - Inner Wing Guns On/Off (only for cannons) = <span style="color: white; background-color: green; padding:0 5px;">LAlt + JOY_BTN2 (bt inferior central)</span>
            - Fire MGs + Wing Cowl Cannons = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN1 (Trigger)</span>
            - Fire Wing Outer Cannons = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN2</span>
- **Bombs:**
    - Activate bombs (Bomb fusing selector) = <span style="color: orange;">manually</span>
        - Bomb release = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN3 (bt superior esq)</span>
- **Rockets:**
    - Activate Rockets (Main rocket switch) = <span style="color: orange;">manually</span>
        - Launch rockets (same bt as 'Bomb release') = <span style="color: white; background-color: green; padding:0 5px;">JOY_BTN3 (bt superior esq)</span>
        - Rocket Emergency Release toggle On/Off = <span style="color: white; background-color: green; padding:0 5px;">RCtrl + NumLock</span>
- **Lights:**
    - Cabin Illumination On/Off = <span style="color: white; background-color: green; padding:0 5px;">Delete</span>
        - Cabin Illumination Brightness = <span style="color: orange;">manually</span>
    - Navigation lights On/Off = <span style="color: white; background-color: green; padding:0 5px;">Insert</span>
- **Miscellaneous:**
    - Canopy:
        - Open = <span style="color: white; background-color: green; padding:0 5px;">E</span>
        - Close = <span style="color: white; background-color: green; padding:0 5px;">LShift + E</span>
        - Bailout = <span style="color: white; background-color: green; padding:0 5px;">LCtrl + E</span>
