# Controls:

**Important:** configurações salvas aqui:
==\My Drive\Hardwares e Softwares\Gaming Configs\XXXXXXXXXXXXXXXXXXXXXXXX==

**Joystick "Axis Tune":**
- Pitch = dead 1 / Curv 5
- Roll = dead 1 / Curv 5
- Rudder = dead 1 / Curv 5
- Throttle = dead 0 / Curv 5

- **Engine & Fuel:**
    - ATA (more/less) = Throttle
    - Throttle to Start (unlock it) = RAlt + Home
    - Throttle to End (lock it) = RAlt + End
    - Radiators control (Open[Auf]/Closed[Zu] = manually;
    - Release External Fuel tank (Jettison Fuselage stores) = NumLock
    - Release MW50/Fuel (Jettison) = not available
- **Navigation:**
    - Stabilizer Trim On/Off = LCtrl + JOY_BTN_POV1_D (baixo)
        - Trim Elevator D = JOY_BTN_POV1_U (cima)
        - Trim Elevator U = JOY_BTN_POV1_D
        - Trim Aileron L = not available
        - Trim Aileron R = not available
        - Trim Rudder L = not available
        - Trim Rudder R = not available
    - Gear Up/Down (Undercarriage) = G
    - Gear Emergency release = LCtrl + G
    - Flaps Up = Seta-cima
    - Flaps Takeoff = Seta-baixo
    - Flaps Landing = RCtrl + Seta-baixo
    - Tail wheel lock/unlock = Pôr o manche todo pra trás, centralizado.
    - Wheel Brake Left = Seta-Esquerda
    - Wheel Brake Right = Seta-Direita
- **Collimator:**
    - Gun Sight Brightness Decrease = RCtrl + JOY_BTN_POV1_D
    - Gun Sight Brightness Increase = RCtrl + JOY_BTN_POV1_U
    - Gun Sight Smoked Screen On/Off = RCtrl + JOY_BTN_POV1_L (esquerda)
- **Machineguns & Cannons:**
    - Safe Mode On/Off = LCtr + JOY_BTN1
        - Inner Wing Guns On/Off (only for cannons) = LAlt + JOY_BTN2 (bt inferior central)
            - Fire MGs + Wing Cowl Cannons = JOY_BTN1 (Trigger)
            - Fire Wing Outer Cannons = JOY_BTN2
- **Bombs:**
    - Activate bombs (Bomb fusing selector), manually;
        - Bomb release = JOY_BTN3 (bt superior esq)
- **Rockets:**
    - Activate Rockets (Main rocket switch), manually!
        - Launch rockets (same bt as 'Bomb release') = JOY_BTN3 (bt superior esq)
        - Rocket Emergency Release toggle On/Off = RCtrl + NumLock
- **Lights:**
    - Cabin Illumination On/Off = Delete
        - Cabin Illumination Brightness = manually
    - Navigation lights On/Off = Insert
- **Miscellaneous:**
    - Canopy:
        - Open = E
        - Close = LShift + E
        - Bailout = LCtrl + E
